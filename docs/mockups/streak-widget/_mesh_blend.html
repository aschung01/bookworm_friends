Mesh blend — how close should the mesh sit to the base?

Every tile below is + vignette + grain, held identical. The only thing changing is the mesh. Two readings of “more opacity” are shown separately, because they pull in opposite directions and only one of them can be what you meant.

Reading A · mesh colours pulled toward the base

The mesh layers stay fully opaque, but each accent hue is mixed toward the base colour underneath it. At 0% the accents are their own hues (what you saw); at 80% they have almost become the base. This makes the mesh tonal — still three light sources, but all in one colour family, so the tile reads rich rather than patchy.

Reading B · same hues, lower alpha

The accents keep their own hues and are faded instead. Worth comparing directly against A: fading a distinct hue leaves a grey cast where mixing toward the base does not, because fading pulls toward whatever is behind rather than toward the base itself.
