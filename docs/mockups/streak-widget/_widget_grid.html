Every line has a label of the form <voice>-<tier>-<variant> — D Duolingo cadence, G guilt, P pleads (desperate), U unhinged. Variant 1 is always the line from the previous round, so nothing already judged has moved. done is absent from Sheet A on purpose: it carries no line in any voice.
