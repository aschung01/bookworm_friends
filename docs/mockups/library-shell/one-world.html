One world, one sheet

A library is always the background. Every tab is the same sheet with different contents. Bar holds the title only; rail appears on Friends.

The rule: background = whose library you’re looking at (yours, or a friend’s once selected). Sheet = the current tab. Dragging any sheet down reveals more of the library beneath it, on every tab. Edit and + are gone — long-press a book to edit, search button to add.
