Capsule tabs, and the rail only on a friend

Rail is gone until someone is selected. Selected tab is a raised white pill; the rest is plain text.

Applied in three places, since it’s one control: Everyone / Activity, the Library Card’s year chips (Flighty uses this exact style for All-Time / 2026), and the read filter. Also — “+ Add Friend” gives search_user_page a home, which it lost when the app-bar search glyph was removed.

The control, full size

Header row plus capsule tabs, as they’d render at real scale.

Friends⋯↑AC
EveryoneActivity+Add Friend
Selected pill is white with a hairline and a soft shadow, so it reads as raised off the sheet rather than as a filled chip. On iOS 26 this is a genuine glass capsule via cupertino_native_better; elsewhere the hairline plus shadow is the fallback. Add Friend uses brandText #067657 rather than Flighty’s blue.
