Six rounds. Round 6 is the live one — the library cat, and a shift from single portraits to a state matrix. Round 6 — the library cat, and a state matrix

live

New subject, and a format shift. The reference is Duolingo's streak-widget grid: 25 tiles of one character across escalating states, not a single portrait. Why a cat beats the worm at the thing that kept failing: ears and a tail are exactly the distinctive bumps the silhouette test wants, so a cat survives being flattened to black where a worm barely does — and a cat has a canonical pose vocabulary (loaf, stretch, curl, arch) so one design covers many states without redesign, which is what a six-moment feature needs.

What this deliberately does not copy from the reference grid is its emotional arc. That set escalates into guilt — hellfire, a skeleton, a demon, “Last chance!” — and 2026-09-12-reading-streaks-design.md already refuses all of it: “amber and never red”, “no red, no broken-flame illustration, no guilt copy”, and a broken streak prints the record, not a zero. That spec also says “No flame” outright — the counter's glyph is the ink stamp and a milestone earns a wax seal. So the grid below escalates awake → asleep rather than calm → damnation, and uses the four state colours that spec defines instead of the reference's five-step heat ramp.

Does the cat carry brand green, or wear it?

settled visually, not argued

Green wins. It is ownable, brand-carrying and Duo-precedented — a green animal is a mascot, a grey tabby is stock illustration, and in the cream version the books end up carrying the brand instead of the character. The cream variant is kept only as the evidence for why.

Four poses from one reference — the consistency test

it holds

All four are /v1/images/edits at 2k against cat-green-cat-v2.png. This is the result that makes the grid feasible: fur colour, cream chest and muzzle, orange inner ears and paws, whiskers, eye treatment and the chalk book with its cream ribbon all survive a complete change of pose. A mascot that can be re-posed can carry six streak states; one that cannot is a single illustration.

The streak matrix — the reference's tile format, this app's state vocabulary: stamp not flame, amber never red, and a break that prints the record.

Silhouette test, round 6 — ears and a tail do the work a worm could not.

What is decided, and the one thing that is not

Decided by this round: the cat is green; the character re-poses reliably from a single reference; and the escalation axis is sleepiness rather than punishment.

Not decided — and it matters more than the drawing. A cat has no heritage here. The package is bookworm_friends, the retired mascot was a worm, and docs/APP_IDENTITY.md records the rename as touching the display name only. Picking a cat means the character has no relationship to the app's own history, where the worm is the original idea. The cat is the better character; the worm is the better story. Worth deciding on purpose rather than by whichever happens to render nicer.

Two bugs this round exposed, both fixed. --reference with a relative path crashed the run after four images had been generated and written — billing for work whose provenance died with the traceback. The path is now resolved, an out-of-tree reference is recorded rather than raising, and the four lost manifest entries are reconstructed and flagged.

Still unkeyed. 2k output is PNG so there are no JPEG artefacts to clean, but the white plate still has to come off via scripts/cutout_bg.py before any of this sits on the dark theme. The tiles above fake it by compositing on the tile colour.

Round 5 — 2k, then refine against ourselves

the worm direction · superseded by round 6

Two levers, neither of them the prompt. First: every one of the previous 25 images was generated at 1k. The endpoint supports 2k, and it is a larger quality jump than anything prompt wording bought — clean vector-grade edges, articulated hands, real eyebrows. It also returns PNG instead of JPEG, which quietly invalidates the note in PROMPTS.md that the endpoint “returns JPEG regardless of response_format”: that is 1k-only behaviour, so 2k skips the lossy step and the artefacts cutout_bg.py has to clean up. Second: an img2img refinement pass seeded with our own best output — the /v1/images/edits route, --reference, asking for the same character with better execution. It holds the design, pose and palette while tightening the linework, which means the character can now be iterated rather than re-rolled.

On seeding with a real commercial mascot instead: not done, and the practical reason is as strong as the legal one. This route copies the seed's geometry — PROMPTS.md already recorded it “faithfully reproduced a crown-shaped ribbon” — so an owl reference returns an owl, which is both off-brief and a trademark exposure for an app that ships. Seeding with our own character gets the same in-context quality lift with neither problem. (Checked while looking: fal has no mascot character to borrow from — their identity is gradient and illustration, no Duo-equivalent.)

Silhouette test, round 5 — the test round 2 failed with nine identical blobs.

Where this leaves it

s6-refine-probe-v2.png is the current best. 2048×2048 PNG, 28.6% ink, brand-green delta 24.1 — inside the close-match band but looser than s5-hybrid-probe-v1.png at 12.2, so if colour fidelity matters more than linework, that is the trade.

Two things the pipeline still needs, and neither is a prompting problem. The plate has to be keyed (scripts/cutout_bg.py) before the character can sit on the dark theme. And the six streak moments need the same character in six poses — the refinement pass shows consistency is achievable, so the honest next experiment is whether --reference holds identity across a changed pose, not just a re-rendered one.

A provenance bug this round exposed and fixed: the manifest was keyed by piece-and-variant, but the endpoint picks the file extension from the resolution — so the 2k run overwrote the 1k entry for the same variant while both files stayed on disk, orphaning two images from their prompts. The manifest is now keyed by filename and the lost entries are recovered and flagged.

Round 4 — vary the prompt, not the subject

superseded by round 5 · 1k

Rounds 1–3 all varied the subject and re-rolled one prompt. Round 4 does the opposite: the subject is fixed — the bookworm holding the chalk book, per the decision below — and the prompt strategy is the variable. What was actually wrong with rounds 1 and 2 was register, not content. Both prompts ran ~2700 characters of rules and negations; long negative lists are weak levers, and naming a thing to forbid it can summon it — round 1 said “NOT a spoon” and returned three spoons. Both described a spec rather than a picture: “10–14 deliberate shapes, two arms, two feet” makes the model do bookkeeping instead of design. Neither named the artifact type. And neither gave the character any personality, which is where appeal actually comes from.

The four strategies, one roll each

$0.16 to find the register

Each is a complete prompt passed verbatim, positive-voice, under ~800 characters. Every one of the four beat every image in rounds 1 and 2 — arms, feet, eyebrows, a mouth, a book, and a silhouette you can read. The differences between them are what round 5 was built from.

s5-hybrid — the synthesis

best of the exploration

s1's art-direction voice (it won on both appeal and silhouette) plus s4's flat-vector discipline (no gloss, so it survives being redrawn as vector), plus two specific fixes the probe exposed: the book is closed and held out to one side so it breaks the outline — s2's worst-in-set silhouette came from an open book held flat against the belly, which sits inside the body mass — and the tail curl is stated explicitly, because it is the single cue that separates a worm from a chick and only s1 kept it. Three short targeted negations survive (no text, no fangs, no gloss), because s3 proved negation is not the problem: with “no text” dropped it wrote BEST BOOK on the cover and grew fangs. A twenty-item wall was the problem.

Silhouette test, round 4 — the same test round 2 failed. Head, segments, curled tail, arm, book with ribbon, two feet.

What this round settles

It was a prompting problem. Same model, same endpoint, same subject, no reference image — the only thing that changed between round 2's blobs and these is how the prompt was written. The transferable rules, in order of how much they bought:

1. Describe the picture, not the rules. Art-direction voice over specification voice. 2. Name the artifact type — “app mascot character design”, “character design sheet”. That single phrase is what produced limbs and a readable build. 3. Give it personality and a moment, not geometry; appeal follows acting. 4. Keep negations few and targeted — three known failure modes, not twenty prohibitions. 5. Say which feature carries the identity (the tail curl, the protruding book) instead of assuming the model will infer it.

Brand green landed too: s5-hybrid-v1 at #00B888, delta 10.0 from #09BC8A, with v3 at 22.4 and v2 at 26.9 — all inside the close-match band, uncorrected.

Still to do before this is an asset: pick one, then key the plate (scripts/cutout_bg.py) and redraw it as vector — which is what lets it be posed across the six streak moments rather than existing as one fixed JPEG.

Round 2 — cuteness first

rejected · all three lost identity

Deliberately outside the chalk system. The brief was baby proportions, oversized low-set eyes with a catchlight, a smile, blush, plush rounded forms, three or four shapes total, brand green plus one warm accent, one character alone with no props. It got cuter and it failed. The silhouette test below is the proof: flatten all nine to black and they are the same blob — three subjects, nine images, one shape. An earlier draft of this page claimed the worm survived. It did not; that read was wrong, and the silhouettes are why. The cause was the brief, not the model. Four of its rules multiply out to a blob and leave nothing to tell one creature from another: three or four shapes, no thin lines or long limbs, nothing else in the frame, and head at least half the height. The mistake underneath was treating cute and minimal as one axis. The reference mascot of this genre is not minimal — beak, eyebrows, two wings, two feet, three tail feathers, 15+ deliberate shapes, several of them thin. It is cute and articulated.

A — the bookmark

identity lost

Cute, and no longer a bookmark. With the book gone there is nothing left to read the ribbon against, so the notched body becomes a generic blob and the orange accents land as ears or arms. The thesis needed the book; the book made it a scene; the scene was the thing that wasn't cute.

B — the bookworm

identity lost

With no book anywhere in the frame a worm is just a slug, and the silhouettes confirm it reads as the same lump as A and C. The one thing worth keeping: b-worm-cute-v3 landed on #10C088 against the brand's #09BC8A — a delta of 8.3, the closest any generated art in this repo has come to brand green without correction, so that colour clause is worth carrying forward even though the drawing is not.

C — the reading lamp

reads as a mushroom

A lamp needs the contrast between a wide shade and a thin stem to read as a lamp, and "no thin lines, plump forms only" removes exactly that contrast. All three rolls are toadstools. Cute, entirely off-brief.

The silhouette test — nine images, three subjects, one blob. This is the finding.

Round 2 at the selected size — a mascot lives at 96pt+; 48 is the stress test.

Decided: (2) — a character inside a chalk-branded app

The launcher icon stays the chalk book. The mascot appears in the six streak moments and the auth hero, at 96pt+ and in colour. Option (1), where the mascot becomes the brand and the chalk book retires to the empty states, is what Duolingo does and is not what we are doing.

That decision has a consequence which also fixes the identity failure. Under (2) the mascot and the chalk artwork share screens, so rather than merely tolerating two visual registers, the mascot holds the chalk book from the icon. The character is smooth full-colour vector; the prop is the brand's own chalk mark, textured and white. That single move does three things at once: it restores the identity anchor round 2 deleted — a worm with no book is a slug, a ribbon with no book is a blob — it gives the silhouette something distinctive to break its outline, and it reconciles the two registers by making them touch instead of sitting side by side.

Round 3 is written and not yet run: --style character in scripts/gen_mascot_art.py. It keeps round 2's proportions, face and the colour clause that produced the 8.3 delta, and reverses the rest — 10–14 deliberate shapes, two arms, two feet, thin elements where they carry meaning, eyebrows for expression, the chalk book as the prop, and the silhouette test stated as a requirement inside the prompt itself.

And a limit worth stating plainly: a text-to-image model produces a concept, not a shippable character. The reference mascot was designed in vector by a studio against a style guide and iterated for years. The realistic path is to use generation to settle which creature and which pose, then have the chosen one redrawn as vector — which is also the only way it survives flutter_launcher_icons, the Android monochrome layer, and being animated across six streak states. Expect round 3 to be good enough to decide from, not good enough to ship.

Still unkeyed. These are JPEGs on flat white. On the dark surface above they sit on their own white plate, because nothing in CSS can fake a keyed colour character. Run scripts/cutout_bg.py before judging dark placement.

Round 1 — the chalk pipeline

rejected · kept as evidence

Generated through the shipped empty-state hand: mid-grey chalk on keyable white, flat, one solid mass, details knocked out as holes. Why it failed, stated so it isn't repeated: that pipeline is a pictogram system, and its constraints are individually the opposite of what a character needs. It mandated no mouth and small eyes. It is monochrome, so nothing could be endearing by colour. It is flat and grainy, so nothing read as soft. It says nothing about proportion, so the model returned adult proportions. And the subjects were scenes — a worm plus a three-book stack, a lamp plus a book — where this genre's mascots are one creature alone. Every one of those is corrected in round 2.

A — bookmark ribbon

reads as a utensil, 3 of 3

A head on a stalk above a book is a spoon or a gear shift. The prompt denied "NOT a spoon" explicitly and got one anyway.

B — bookworm on a stack

best of the round

Correct construction, clean knock-outs, no antennae so no Bugdroid silhouette — and still not a character anyone would want to meet.

C — reading lamp

a scene, not a character

Two objects with a gap, so the gap closes into clutter at 40pt, and the cut-out eyes land as stickers on furniture.

What round 1 still proves

Ink coverage worked as a predictor. All nine landed 21.6–28.3% against the shipped set's 21.3–34.7% and the 7.3% that got dashed nomatch rejected, so knocking details out as holes does reliably keep a pictogram legible at spot size. That lesson survives; it just isn't what makes a mascot.
