Libstack 1.1.0 — store screenshots

12 frames per locale, en-US and ko, every one at its exact required size. Showing the framed store asset by default — switch to Raw capture for the bare device screenshot underneath. Click any frame for full resolution. Taken off the App Review demo account, so these are the screens a reviewer sees when they sign in.

Recaptured 2026-10-01 against build 15. The previous set predated the reading streak and drew a UI that no longer shipped — a rust bar flame instead of kCandleFlame #F2A93F, an unfilled grey streak tile, and a p.259 / 432 band from before the status/progress merge. All of that is gone.

Three things about how these were made, all of which change what you can trust. The streak page was captured from a build with debugStreakUndoVisibleOverride = false, because streakUndoVisible follows kDebugMode and a simulator cannot be built in profile or release — so without it every capture carries a “Today is recorded. / Undo” footer the shipping app does not have. The month card is paged back to September: it was captured just after midnight on 1 October, when the current month held exactly one stamped day. And the ko set was captured with the simulator’s system language set to Korean and then rebooted — not with a -AppleLanguages launch argument, which does put the app into Korean but leaves the iPad’s status bar reading Thu Oct 1 in English and leaves a “◀ Safari” breadcrumb in the corner of every frame.

The framed files are not on disk. They are gitignored — 28MB across the two locales — so they are built rather than committed. Run flutter test test/store_frame_render_preview.dart (about 10 seconds) and reload, or switch to Raw capture.
