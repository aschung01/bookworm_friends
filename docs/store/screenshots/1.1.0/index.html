Libstack 1.1.0 — store screenshots

12 captures, every one at its exact required size. Click any frame for full resolution. Taken off the App Review demo account, so these are the screens a reviewer sees when they sign in.

Recaptured 2026-10-01 against build 15. The previous set predated the reading streak and drew a UI that no longer shipped — a rust bar flame instead of kCandleFlame #F2A93F, an unfilled grey streak tile, and a p.259 / 432 band from before the status/progress merge. All of that is gone.

Two things about how these were made, both of which change what you can trust. The streak page was captured from a build with debugStreakUndoVisibleOverride = false, because streakUndoVisible follows kDebugMode and a simulator cannot be built in profile or release — so without it every capture carries a “Today is recorded. / Undo” footer the shipping app does not have. And the month card is paged back to September: it was captured just after midnight on 1 October, when the current month held exactly one stamped day.
